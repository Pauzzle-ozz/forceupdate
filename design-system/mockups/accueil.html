Hors ligne

Le serveur local ne répond plus

Il a sans doute été arrêté (Ctrl+C dans le terminal). Le relancer avec forceupdate ui, puis ouvrir l'adresse qu'il affiche.

Session terminée

Le serveur a redémarré : son jeton a changé. Ouvrir l'adresse que forceupdate ui affiche dans le terminal (elle contient le nouveau jeton). Les analyses de la session précédente sont perdues ; les chemins récents restent.

Pas de réseau

L'analyse n'utilisera que le cache : ses données peuvent dater de plusieurs jours, et ce qui n'y est pas sortira « non concluant ». L'option « Hors ligne » est cochée.
